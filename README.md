# Menaphite Remedy Reminders

Reminds you to sip a Menaphite remedy before a divine potion or saturated heart boost expires, in order to turn it into a regularly decaying boost.

- Configurable reminder timing (default: 10 seconds).
- Supports notifications, a countdown infobox, or overhead text.
- Reminders only appear while you carry a Menaphite remedy.
- Individual toggles per-potion. Saturated heart is off by default.
- Under Misc, heart reminders default to only when the heart is absent from your inventory.
